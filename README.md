# Point Processing: Gamma Correction and Tone Processing

This repository provides all required deliverables for an educational project on point processing focused on gamma correction and tone processing.

```text

│   └── further_reading/
│       ├── paper1.pdf

│       ├── paper3.pdf

├── notebook/

│   └── README.md
└── requirements.txt
```

## Run the Simulator

```bash
pip install -r requirements.txt
streamlit run simulator/app.py
```

## Notebook

Open and run `notebook/Point_Processing_Walkthrough.ipynb` top to bottom.

## Notes

- The study notes and quiz explanation are included as DOCX and PDF.
- The `quick_reference.txt` file provides a compact cheat sheet.
- `quiz/quiz_link.txt` includes a public Google Form URL placeholder to replace with your team form.
